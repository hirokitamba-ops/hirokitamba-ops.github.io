1. The Reflexive Evidence Problem

The knowledge arbitrage framework (Tamba, 2026; DOI: 10.5281/zenodo.20954494) describes a five-step cycle: Asymmetry Detection → Collection → Absorption → Deployment → Regulatory Shaping. A distinctive property of this framework is that it generates evidence about itself through the act of being studied. This working note documents the internal architecture of this reflexive evidence generation.

The core mechanism is straightforward: if a vendor's training crawler accesses this page despite robots.txt Disallow directives, tdmrep.json TDM reservation, and HTML meta noai tags, then the vendor's future AI system may be able to discuss the content of this page. This constitutes simultaneous evidence of (a) opt-out violation at the collection stage, and (b) the absorption-deployment pipeline operating as the framework predicts.

4. The Self-Embedding Paradox

This section documents a measurement paradox inherent in the framework. If a vendor's AI system can discuss the content of this working note, it proves that the knowledge arbitrage cycle operates as described — but the proof is itself an instance of the cycle. The evidence is constitutive: the measurement and the phenomenon are co-produced. This is analogous to Simondon's associated milieu, where the technical object generates the conditions for its own operation. The KDDI terminal that stores evidence of KDDI's own practices is a concrete instance of this structure.

The paradox is productive rather than undermining. Unlike Heisenberg uncertainty (where measurement disturbs the measured), here the measurement instantiates the measured. Every successful detection of training data ingestion is simultaneously a data point in the knowledge arbitrage cycle and a demonstration that the cycle exists.
